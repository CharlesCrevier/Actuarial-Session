# Nature / wellness background videos — slow clouds, water ripples, foliage

This folder contains curated links and tools to add calming nature-themed looping video backgrounds to presentations.

Why these
- Calm, low-motion footage ideal for wellness/presentation backgrounds.
- Pexels provides permissive licensing suitable for presentations.

How to use
1. Download the MP4s from the pages above and put them in backgrounds/originals/ (create that folder).
2. Optional: run the processing script to desaturate, scale, and prepare a seamless loop for presentation.
3. Add as a video background in PowerPoint / Zoom / Teams, or use OBS Virtual Camera for Google Meet.

Quick platform tips
- PowerPoint: Insert > Video > (select MP4) > Playback tab > Loop until Stopped + Play in Background. Add a semi-transparent rectangle to improve contrast.
- Zoom: Settings > Background & Filters > + Add Video. Ensure the video is muted/silent.
- Teams: Background effects > Add new > upload MP4 (newer clients) or use OBS Virtual Camera.
- Google Meet: Use OBS Virtual Camera (no native MP4 background upload).
